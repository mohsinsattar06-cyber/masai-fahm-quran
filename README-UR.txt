مساعی فہم القرآن جلد اول — مفت ویب ایپ پیکج

اس پیکج میں شامل ہے:
1) index.html — آپ کی محفوظ شدہ اصل HTML فائل؛ اس کے کتابی متن میں اس مرحلے پر کوئی تبدیلی نہیں کی گئی۔
2) manifest.webmanifest — ویب ایپ کی شناخت اور انسٹالیشن کی معلومات۔
3) sw.js — بنیادی آف لائن کیشنگ۔
4) icon-192.png اور icon-512.png — ایپ آئیکنز۔

اہم:
- یہ PWA ابتدائی پیکج ہے، Google Play / Apple App Store / Microsoft Store کی مکمل native ایپ نہیں۔
- انسٹالیشن اور Service Worker کے لیے اسے HTTPS ویب ہوسٹنگ پر شائع کرنا ہوگا؛ صرف HTML فائل کو ڈبل کلک کرنے سے PWA انسٹالیشن فعال نہیں ہوگی۔
- اس ورژن میں صارف لاگ اِن، PKR 200 ادائیگی، رسید اپ لوڈ، ایڈمن منظوری، سرور ڈیٹابیس یا ہیکنگ سے تحفظ کا مکمل بیک اینڈ شامل نہیں۔ یہ اگلا مرحلہ ہے اور اس کے لیے محفوظ سرور/ڈیٹابیس درکار ہوگا۔
- اصل HTML میں سبق 87 کے بعد ایک اختتامی پیراگراف موجود ہے۔ اسے اس لیے برقرار رکھا گیا ہے کہ کتابی متن میں آپ کی اجازت کے بغیر تبدیلی نہ ہو۔ اگر آپ اسے ہٹانا چاہتے ہیں تو اگلے مرحلے میں صرف آپ کی واضح ہدایت پر ہٹایا جائے گا۔

استعمال:
اس فولڈر کے تمام اجزاء ایک ہی ویب فولڈر میں HTTPS ہوسٹنگ پر اپ لوڈ کریں، پھر ویب سائٹ کھولیں۔ براؤزر کی Install app / Add to Home Screen سہولت سے موبائل یا کمپیوٹر پر انسٹال کیا جا سکتا ہے (براؤزر اور آپریٹنگ سسٹم کے مطابق سہولت مختلف ہو سکتی ہے)۔
